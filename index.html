Attendance Tracking Robot

An autonomous 4-wheeled robot that follows a line route between offices, stops at each one to scan faces with an ESP32-CAM + OpenFace pipeline, and logs attendance with timestamps.

ESP32-CAMPythonOpenFaceComputer Vision

Built on an Arduino Uno with an L298D motor shield, TCRT5000 line sensors and an HC-SR04 obstacle sensor. Faces are detected with SSD and converted to 128-D embeddings via OpenFace, then matched by cosine similarity against a JSON employee database. Navigation uses fuzzy logic and magnetic stop markers, and a Tkinter GUI lets admins manage profiles and review the attendance log. Tested to 92% recognition accuracy under normal office lighting.

StoreBot — Store Delivery Robot

A mall delivery robot that carries products from the store to the customer, coordinated by a web page and database, with GPS navigation, obstacle avoidance, and RFID access control.

ESP32Arduino MegaGPS (NEO)RFID

An ESP32 handles connectivity and forwards client requests to an Arduino Mega, which drives the motors and reads ultrasonic, tilt, flame, and Ublox NEO GPS sensors. A web page and database assign an available robot or ask the client to wait 30 minutes, while an RFID + servo mechanism releases the purchase only for authorized cards. The project vision proposes upgrading to a Raspberry Pi with ROS, computer vision, and solar charging.
