<section class="section container" id="projects">
<div class="section-heading heading-row">
<div>
<p class="eyebrow">ENGINEERING WORK</p>
<h2>Projects that <span class="gradient-text">move ideas forward.</span></h2>
</div>
<span class="section-note">02 featured projects</span>
</div>
<div class="project-grid">
<article class="project-card">
<div class="project-visual">
<img class="project-image" src="assets/images/attendance-robot.jpg" alt="Attendance tracking robot project"
width="1200" height="675" loading="lazy">
<span class="visual-label">ROBOTICS / COMPUTER VISION</span>
</div>
<div class="project-body">
<div class="project-meta"><span>01 / THESIS PROJECT</span><span class="pill">92% accuracy</span></div>
<h3>Attendance Tracking Robot</h3>
<p>An autonomous 4-wheeled robot that follows a line route between offices, stops at each one to scan faces
with an ESP32-CAM + OpenFace pipeline, and logs attendance with timestamps.</p>
<div class="tag-list"><span>ESP32-CAM</span><span>Python</span><span>OpenFace</span><span>Computer
Vision</span></div>
<div class="project-details">
<button type="button" class="project-details-toggle" aria-expanded="false"
aria-controls="project-overview-1">
Project overview <span class="project-details-icon" aria-hidden="true">＋</span>
</button>
<div class="project-details-body" id="project-overview-1">
<p>Built on an Arduino Uno with an L298D motor shield, TCRT5000 line sensors and an HC-SR04 obstacle
sensor. Faces are detected with SSD and converted to 128-D embeddings via OpenFace, then matched by
cosine similarity against a JSON employee database. Navigation uses fuzzy logic and magnetic stop
markers, and a Tkinter GUI lets admins manage profiles and review the attendance log. Tested to 92%
recognition accuracy under normal office lighting.</p>
</div>
</div>
</div>
</article>
<article class="project-card">
<div class="project-visual">
<img class="project-image" src="assets/images/delivery-robot.jpg" alt="StoreBot delivery robot project"
width="1200" height="675" loading="lazy">
<span class="visual-label">AUTONOMY / NAVIGATION</span>
</div>
<div class="project-body">
<div class="project-meta"><span>02 / ROBOTICS</span><span class="pill">StoreBot</span></div>
<h3>StoreBot — Store Delivery Robot</h3>
<p>A mall delivery robot that carries products from the store to the customer, coordinated by a web page and
database, with GPS navigation, obstacle avoidance, and RFID access control.</p>
<div class="tag-list"><span>ESP32</span><span>Arduino Mega</span><span>GPS (NEO)</span><span>RFID</span>
</div>
<div class="project-details">
<button type="button" class="project-details-toggle" aria-expanded="false"
aria-controls="project-overview-2">
Project overview <span class="project-details-icon" aria-hidden="true">＋</span>
</button>
<div class="project-details-body" id="project-overview-2">
<p>An ESP32 handles connectivity and forwards client requests to an Arduino Mega, which drives the motors
and reads ultrasonic, tilt, flame, and Ublox NEO GPS sensors. A web page and database assign an
available robot or ask the client to wait 30 minutes, while an RFID + servo mechanism releases the
purchase only for authorized cards. The project vision proposes upgrading to a Raspberry Pi with ROS,
computer vision, and solar charging.</p>
</div>
</div>
</div>
